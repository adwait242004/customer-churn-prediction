# Customer Churn Prediction using Machine Learning

Predicts whether a customer will leave (churn) and finds which factors cause it.

## How to run
```bash
pip install -r requirements.txt
python churn_prediction.py
```
Charts are saved in the `outputs/` folder.

## Files
- `churn_prediction.py`  -> complete project (8 simple steps, fully commented)
- `customer_churn.csv`   -> dataset
- `INTERVIEW_NOTES.md`   -> how to explain this project in an interview

## Using the real Kaggle dataset
Download "Telco Customer Churn" from Kaggle, save it as `customer_churn.csv`
in this folder (replace the file), and run the script again. No code change needed.
