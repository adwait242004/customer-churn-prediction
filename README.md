# Customer Churn Analysis and Prediction

## Project Overview
This project analyzes customer data and predicts whether a customer is likely to leave a company using machine learning.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Machine Learning Algorithms
- Logistic Regression
- Random Forest Classifier

## Project Workflow
1. Load customer data from a CSV file.
2. Clean and preprocess the data.
3. Perform exploratory data analysis (EDA).
4. Encode categorical variables and prepare features.
5. Split the dataset into training and testing sets (80:20).
6. Train Logistic Regression and Random Forest models.
7. Evaluate model performance using accuracy, precision, recall, F1-score, and a confusion matrix.
8. Predict whether a customer is likely to churn.

## How to Run
1. Install Python.
2. Install the required libraries:

   `pip install pandas numpy matplotlib seaborn scikit-learn`

3. Place the dataset in the project folder.
4. Run:

   `python churn_prediction.py`

## Purpose
The project demonstrates how machine learning can help identify customers who may be at risk of leaving a company.
